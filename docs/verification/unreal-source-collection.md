## 採集規則與檢查

同一層的重複連結先去重，再發出請求。
已取得的固定文件不會重新下載。
失敗頁面在續跑時重試。
錯誤版本、重複 URL、缺少有效摘要及未固定版本的子連結會被拒絕。

工具每秒最多開始一個請求。
遇到 HTTP 429 時，共用等候狀態會遵守 `Retry-After`。
等待時不持有共用鎖，其他執行緒可以更新等候狀態。

九項來源採集測試通過。
測試涵蓋重複子連結、相同遍歷結果、失敗重試、循環連結、版本及摘要防護、固定檔案的 seed 鏈，以及流量限制的等待時間。
加上網格比較工具，本地共有 19 項 Python 測試通過。
