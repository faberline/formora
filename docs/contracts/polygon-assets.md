## 目標
接續 #30，建立可保存原始多邊形與邊的 Rust 資產。屬於 #3 的基礎工作。所有 milestone 的完整驗收與前置條件保持不變。

## 交付內容
- 既有 MeshAsset 加入穩定 ID 的邊與多邊形。保存面頂點順序、面角 UV、面角／面法線、平滑旗標、材質槽及 UV 層順序／作用層。
- 保存鬆散邊、位置重合但 ID 不同的頂點、共用邊及非流形連接。拒絕遺失引用、重複邊端點配對、重複 JSON ID、錯誤屬性長度及非有限值。
- Rust 將簡單凹多邊形切成三角形。繪製與點選使用同一結果。切分只供預覽，不覆寫原始面與 ID。
- Agent 可經 CLI 與 MCP 查詢切分結果及退化面診斷。既有三角資產、房間、門與保存格式仍可載入。

## 固定驗收條件（實作前）
- 既有 57 組 Blender 5.2.3 基本形狀資料，經真實 CLI 輸入資產、儲存、重開與查詢後，由既定比較器逐項檢查頂點、邊、有方向面、UV、面／面角法線、平滑旗標與變換。維持既定 1e-6 數值上限。這是資料保存驗收，不是基本形狀生成驗收。
- 多 UV 層案例須保持名稱、順序與作用層。局部改點、undo 及重開不改變其餘連接、ID 或面角屬性。
- 凹多邊形、反向面、旋轉平面、共線角與不同大小的固定案例須通過。切分不得填滿凹口。簡單非退化面輸出的有向三角面積和須在正規化面積 1e-10 內；不得產生面外或反向三角形。
- 完全退化的面保留在資產中。切分回傳零三角形與明確診斷。自相交面的切分／預覽須明確失敗，不發布部分幾何。失敗不得改動已保存的資產或 undo。
- 固定效能樣本：10,201 頂點、20,200 條邊、10,000 個四邊面。在 Apple M1 Max、macOS、release build 測試三次。每次驗證 <= 250 ms；切分 <= 500 ms；建立／改點／存檔／載入合計 <= 2 s。沿用 #30 的舊樣本及原上限，不能放寬。
- 本地 Rust 格式、Clippy、單元／真實 CLI／MCP 測試、官方 MCP SDK，以及現有三平台 CI 須通過。macOS Metal 實際渲染凹面並驗證凹口未填滿、改點可見、重開結果一致。
- 合併後核對與已測候選內容相同，記錄版本與證據，經 Codex 獨立驗收後才關閉本 issue。

## 本 issue 不代表完成的功能
不宣稱基本形狀生成、完整編輯工具、雕刻、UV 編輯、材質貼圖、平滑法線生成、完整世界規模效能、鬆散邊的原生顯示／點選或 Windows/Linux GPU 驗收。三角切分不是源多邊形拓撲驗收的替代品。0.0 的完整功能對照仍需完成。
