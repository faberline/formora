## 固定品質條件（實作前）
- 實際 Rust 生成固定 mesh-primitives suite 的全部四種形狀，共 27 組新案例。保留先前四種形狀的 20 組，合計 47 組。
- 每組經 CLI 與官方 MCP 生成、儲存、重開及查詢。不能用參考頂點作為生成輸入。沿用既定比較器的精確有向拓撲、邊、逐面角 UV／法線、平滑旗標、變換與邊界。全部數值上限維持 1e-6，不為通過降低標準。
- 加入現有 context 資料中的 15 組新幾何邊界子檢查：球面零半徑，圓柱／圓錐零半徑、零深度及同半徑，圓環零主／次半徑、全部為零及反向內外半徑。保留先前七組，共 22 組。只驗證幾何資料，不複製尚未實作的選取、來源或建立情境欄位；完整 context 驗收仍未執行。
- 球面接縫、極點及面角 UV 必須正確。圓柱／圓錐支援未填面、n-gon 及三角扇端蓋，以及單一尖端、截錐、倒錐。圓環支援主／次半徑及內／外半徑參數模式。
- 零半徑球面依上游結果保留一個頂點。上下半徑皆零的柱／錐依上游結果保留兩個頂點與一條邊。圓環保持原有拓撲，不合併位置相同的頂點。未定義資料不得當作數值零誤差。
- 參數範圍依固定 RNA 資料；先檢查算術與資源預算再配置。超限或錯誤請求須原子失敗。保存參數、手動編輯標記、共享引用、重建、undo 及診斷沿用共用核心。

- Rust 1.85 格式、Clippy、完整 Rust 測試、Python 比較器測試及既有官方 MCP 測試都須通過。

- macOS Metal 實際渲染四種新形狀，分別驗證改參數後可見變化及重開一致。
- 所有必要三平台 CI、依賴 PR 整合與本候選整合後的 Codex 獨立驗收通過前，本 issue 保持開啟。
