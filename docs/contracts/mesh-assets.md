## 目標
為 #3 建立 Rust 三角網格資產基礎。先行基礎工作不代表 0.2 已通過；#1、#2 與各 milestone 的前置驗收仍有效。

## 實作範圍
- 共用資產有穩定的字串頂點與三角面 ID、有限座標、面角 UV、可選面角法線及材質槽。
- 場景實體可引用同一資產。提供新增／整體替換、依 ID 改頂點及刪除命令。
- CLI 與 MCP 使用同一操作核心，支援資產查詢、預期 revision、儲存、重開、undo 及錯誤回復。
- 原生預覽與點選使用同一三角幾何。保留舊版房間、門與 Cube/Plane 載入能力。

## 固定驗收標準（實作前）
- 座標、UV 與法線儲存重讀須逐值保持；預覽位置須在 1e-6 公尺內。使用已固定 Blender 5.2.3 的 plane/cube 參考幾何測試儲存與轉換，這不算基本形狀生成驗收。
- 不合併位置相同但 ID 不同的頂點。局部改點必須保留其餘 ID、連接、UV、法線與材質槽。
- 拒絕重複 JSON ID、遺失頂點／資產／材質引用、非有限值與錯誤屬性長度。被引用的資產不能刪除。不接受部分寫入；失敗須保留記憶體、磁碟與 undo 狀態。
- 有限的零面積三角形可保存。預覽省略零面積三角形，不產生 NaN。
- 自動測試須涵蓋 CLI/MCP 同結果、儲存重開、共享資產、修改、undo、錯誤與實際幾何點選。macOS 執行原生 Metal 渲染並檢查輸出。
- 固定效能樣本：10,201 頂點、20,000 三角形平面網格。在本機 Apple M1 Max、macOS、release build 測試三次。每次驗證 <= 250 ms；建立／改點／存檔／載入合計 <= 2 s。記錄各次時間與版本。超標不能調低標準。這不是完整產品效能驗收。
- Rust 格式、Clippy、測試與現有三平台 CI 須通過。整合後由 Codex 核對內容與有限範圍證據，再關閉本 issue。

## 排除與後續
本 issue 是三角資料與操作基礎。一般多邊形拓撲、鬆散邊、選取／編輯模式、基本形狀生成、UV 編輯、貼圖顯示、平滑法線生成、雕刻、完整建模效能與跨平台 GPU 驗收仍未完成。不得用這批測試宣稱 Blender 建模功能對齊。
