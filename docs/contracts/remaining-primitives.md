# Remaining primitive implementation contract

## 目標與依賴
接續 #36 / PR #37 與 #40 / PR #41，在同一 Rust 核心加入二十面球與 Suzanne 猴頭。屬於 #3。依賴鏈的 CI、整合及獨立驗收條件保持不變。

## 固定交付條件（實作前）
- 生成器種類使用 ico_sphere 與 monkey。CLI 與 MCP 共用參數、資源預算、配方保存、建立、重建、診斷及錯誤回復。
- 二十面球接受固定 RNA 的細分 1..10、半徑、UV 開關及有效建立縮放／旋轉選項。依固定來源計算細分拓撲、球面位置與逐面角 UV；不可用不符來源結果的其他細分方式取代。
- Suzanne 使用固定 Blender 原始碼中的作者模型表、對稱規則與 UV 表。以 Rust 編譯資料與運算生成。記錄來源 commit、blob、雜湊、生成工具及 GPL 通知。不能把執行捕獲的參考頂點當成實作資料。
- 執行檔不得讀取 baseline/reference、測試輸出、Blender 或 Python 來生成幾何。二者均須保存穩定 ID、共享引用、參數及已編輯標記。重建支援保存參數或新參數，並支援 undo。
- 分配前以 checked arithmetic 估算頂點、邊、面及面角總數。二十面球設 n=2^(subdivisions-1)，總數為 120*n*n+2。Suzanne 保持 507 頂點、1005 邊、500 面與 1968 面角，合計 3980。不得因預算不足默默降低細分。

## 固定品質條件
- 原有 mesh-primitives 的剩餘十組案例由真實 Rust 指令生成。與既有 47 組合併，兩種介面各跑全 57 組。保留原有有向拓撲、邊、逐面角 UV／法線、平滑旗標、變換與邊界比較；數值上限保持 1e-6。
- 原有 context 資料的 ico_sphere_zero_radius 與 monkey_zero_size 各增加幾何子檢查。保留先前 22 組，共 24 組。兩種介面合計須通過 162 組比較。完整建立情境驗收仍未執行，不複製尚未實作的來源／選取標記。
- 零半徑、零尺寸與退化縮放保持原有邏輯 ID 和拓撲。尺寸零時 Suzanne 不變成其他形狀。建立矩陣與面／面角法線依固定來源精度驗證。
- 保留所有既有 1060 組選取比對、57 組 payload、官方 MCP、完整 Rust 與 Python 回歸。錯誤參數、重複 ID、非有限值、預算超限、stale revision 與儲存失敗須原子回復。

## 固定效能與成果條件
- 真正 Rust 1.85.0 的格式、Clippy、完整 Rust 測試與 Python 測試必須通過。固定絕對編譯器路徑及匹配 PATH，記錄實際子工具版本與 compiler cache。
- Apple M1 Max / macOS / release，二十面球細分 6 與預設 Suzanne 各量測三次。純生成 <=500 ms；建立、改參數重建、儲存及重讀合計 <=2000 ms。前者改半徑 1→1.5，後者改尺寸 2→3。保留全部原有效能案例與門檻。
- Metal 各渲染一個獨立模型，分別檢查原始可見、改參數可見及新程序重開圖片完全一致。保留請求、執行檔、原始碼、shader、輸出與雜湊。
- 複製執行檔到原始碼庫外，拒絕所有原始碼庫讀取後，仍能依未見過的參數生成兩種模型。保留拒絕控制組與實際輸入、輸出。
- 必要三平台 CI、所有依賴整合及整合後 Codex 獨立驗收通過前，issue 保持開啟。未執行或失敗的必要關卡不能當作通過。
